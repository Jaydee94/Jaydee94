## 👋 About Me

Hey, I'm **Jan** — a Cloud Engineer based in **Koblenz, Germany** 🇩🇪.

I work with **Kubernetes** and **OpenShift** professionally and love building open-source tools that make the cloud-native ecosystem easier to use. When I'm not automating infrastructure, I'm tinkering on home lab projects or diving into new languages.

- 🔭 Building cloud-native tools in the **Kubernetes / OpenShift** ecosystem
- ⭐ Creator of **[kubeseal-webgui](https://github.com/Jaydee94/kubeseal-webgui)** — 83+ stars, a web UI for Bitnami Sealed Secrets
- 🤖 Exploring **AI-powered CLI tooling** with [parselmouth](https://github.com/Jaydee94/parselmouth) (Python + Google Gemini)
- 🏠 Running a self-hosted **home lab** (Paperless-ngx, Ansible automation, Docker)
- 🌱 Currently learning **Rust** and **Go**
- 🎮 Gaming enthusiast — including 7 Days to Die modding
